# 웨스트진 입고 · OUT 관리 — 설치 파일

웨스트진베이커리 매장용 **입고 · 마감 · OUT 리스트 · 본사 주문서** 관리 프로그램의 **설치 파일만** 올리는 곳입니다.
소스 코드는 공개하지 않습니다.

## 받기
[Releases](https://github.com/Grizzlyee/westgin-releases/releases/latest) 에서 최신 버전을 받습니다.

| 파일 | 쓰는 곳 |
|---|---|
| `WestginOrder_Setup_<버전>_32bit.exe` | **매장 POS** (32비트 윈도우) — 64비트 윈도우에서도 돌아갑니다 |
| `WestginOrder_Setup_<버전>.exe` | 64비트 윈도우 PC |
| `version.json` | 프로그램의 '업데이트 확인'이 읽는 정보 (버전 · 크기 · sha256) |

이미 설치된 프로그램은 **설정 > 업데이트 > 업데이트 확인** 으로 여기서 새 버전을 받습니다.
